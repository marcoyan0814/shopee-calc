# 🛒 蝦皮刷刷

蝦皮刷刷是以原生 HTML、CSS 與 JavaScript 製作的單頁計算工具，不需要後端或第三方套件，可直接部署至 GitHub Pages。

線上版本：<https://marcoyan0814.github.io/shopee-calc/>

網站提供 Web App Manifest、Android/PWA 圖示與 Apple Touch Icon，可從手機瀏覽器選擇「加入主畫面」，以「蝦皮刷刷」名稱和專屬圖示開啟。

## 三種使用模式

### ⚡ 快速試算

- 輸入原價與回饋金額，計算折後金額與實質折數。
- 支援 `+`、`-`、`*`、`/` 與括號算式。
- 支援多重折數連續換算，例如 `94+93+95`。

### 🎯 商品湊單

- 貼上多筆商品金額並選擇購買數量。
- 支援主折價券搭配額外折價券、蝦幣回饋或滿額折現。
- 可直接輸入商品總原價，不一定要建立商品清單。
- 使用 DFS 搜尋目標折後金額附近的 TOP 5 商品組合。
- 桌機使用表格呈現結果，手機改用排名卡片。

組合推薦規則：

- 只有四捨五入後金額尾數為 `48` 或 `88` 的商品會參與計算。
- 在目標金額加 10% 的範圍內，優先選擇實質折數最低的組合。
- 折數相同時，再依與目標金額的差距排序。
- 搜尋超過 50 萬種組合時會停止並提示縮小範圍，避免瀏覽器凍結。

### 🧮 優惠券配對

與 LINE「配」指令使用相同規則，不需要商品清單：

- 主券及次券列表以逗號分隔，例如 `90,95,85/2000`。
- 蝦幣券使用百分比，例如 `5%/1000`。
- 找出實質折數最低的券組合與建議刷取金額。
- 提供建議金額往下 5% 的自湊區間。
- 每張優惠券在各推薦名次中只使用一次。
- 可限制折後應付上限並顯示 1～10 名結果。
- 主券及次券皆無上限時，顯示「不限金額（折數固定）」。

## 商品資料與設定

- 初次開啟時商品清單保持空白，可自行貼上價格或按「載入範例」。
- 支援蝦皮分享文字、千分位逗號與 `$` 符號。
- 可將商品、優惠條件、操作模式及優惠券列表儲存在 Cookie 365 天。
- 所有資料只保存在使用者瀏覽器中。

## 本機使用

直接開啟 `index.html`，或啟動任意靜態檔案伺服器：

```bash
php -S 127.0.0.1:8080
```
