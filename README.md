# 🛒 蝦皮購物折扣回饋與組合推薦平台 (蝦皮刷刷)

「蝦皮刷刷」是一個輕量且高效的單頁網頁應用程式 (SPA)，專門為蝦皮購物買家與賣家設計。本工具可協助使用者輕鬆計算商品組合的折價券折扣、蝦幣回饋，並透過全組合演算法自動尋找最接近目標消費金額的最佳商品數量組合。

---

## 💡 核心功能特色

### 1. 📋 商品金額解析、快速折扣試算與計算來源選擇
- **雙欄彈性佈局**：
  - **左欄 (商品原價與匯入)**：在輸入框貼上商品說明與金額（自動過濾 `$`、逗號與中文字），點擊「📥 匯入商品價格至列表」即可自動提取金額。
  - **右欄 (⚡ 折扣快速計算)**：提供獨立的「金額」與「回饋」算術試算面板。
    - **支援四則算術表達式**：可直接輸入包含 `+` 與 `*` 的算術表達式（例如：`400+100*2`），嚴格遵循**先乘除後加減**之數學優先順序解析。
    - **即時折數分析**：自動展開顯示「總原價」、「總折扣金額（含拆解算式）」、「折後金額」與「精確折數 (相當於省下約 X.XX%)」。
    - **🧮 雙重/多重折數連續換算**：支援在「連折換算」欄位中輸入如 `94+93`（代表 94 折再打 93 折），即時精確換算出連折後的綜合折數（如 $87.42$ 折，相當於省下約 $12.58\%$）。
- **計算來源二選一**：
  - **使用商品清單**（預設）：可對清單中各個商品單獨選擇 0~3 數量進行細部試算與 TOP 5 組合精算。
  - **使用商品總原價**：隱藏商品清單，直接輸入「自訂商品總原價」（預設帶入當前清單總和，且**支援 `+` 與 `*` 四則算術表達式**，如 `71548+20088*2`），快速計算各項優惠折抵結果。
- **數量選取下拉選單**：每個商品皆有獨立的 0、1、2、3 數量選取選單，切換時即時更新小計與總原價。
- **📱 全響應式 (RWD) 介面設計**：全面針對智慧型手機與平板電腦進行螢幕與觸控優化，支援單欄流動 Stack 排版、滿版大觸控按鈕與平滑表格滑動。
- **💾 Cookie 設定記憶功能**：提供「儲存設定至 Cookie」按鈕，能將商品價格文字、快速折扣算式、已匯入商品清單與試算數量、計算來源模式、折價券、蝦幣回饋及目標金額設定完整儲存在瀏覽器中（期限 365 天），下次重開頁面時自動回復完整狀態與試算金額。

### 2. 💰 折價券與蝦幣回饋即時試算
- **主折價券計算**：對「總原價」進行主折價券折抵（如 94 折與上限）。
- **💡 封頂金額自動回推提示**：
  - 在 **「折價券折扣上限」**、**「額外折價券折扣上限」** 與 **「蝦幣回饋上限」** 欄位輸入金額時，系統會自動根據折數/回饋率，於欄位下方即時顯示「💡 封頂金額 $XXXX」（包含總原價封頂金額與折後基準封頂金額）。
- **次要優惠 (三選一擇一使用)**：
  - **選項 1：額外折價券**：以「主折價券折抵後金額」為基準進行第二張折價券計算（如 94 折與折扣上限）。
  - **選項 2：蝦幣回饋**：以「主折價券折抵後金額」為基準計算蝦幣回饋（如 5% 與蝦幣上限）。
  - **選項 3：低消折**：當「主折價券折抵後金額 $\ge$ 低消門檻（預設 80,000 元）」時，直接折抵設定金額（預設 5,000 元）。
- **綜合回饋分析與公式**：
  - **主折價券金額** = 總原價 × (1 - 主折價券折數%)
  - **次要優惠基準** = 總原價 - 主折價券金額
  - **折扣後實際金額** = 次要優惠基準 - 次要折扣金額 (額外折價券或低消折)
  - **回饋總額** = 主折價券金額 + 次要折扣金額 + 蝦幣回饋金額

### 3. 🎯 目標金額最佳商品組合推薦 (TOP 5 組合精算)
- **DFS 全組合搜尋**：採用深度優先搜尋 (Depth-First Search) 演算法，對所有商品進行數量組合搭配測試。
- **自訂組合條件**：
  - **目標折後金額 (Y 元)**：設定欲達成的滿額門檻或預算目標（例如 80,000 元）。
  - **單種商品數量上限**：限制每種商品最多可選購的件數（1 ~ 10 件）。
- **TOP 5 最佳推薦排名**：
  - 標題自動附帶當前計算條規（如：`（折價券 94 折，上限 0元；蝦皮回饋 5%，上限 4,000元）`）。
  - 將「目標折後金額 + 10%」設為可接受上限，容許為了取得最佳折數而微幅超過目標。
  - 可接受範圍內依「實質折數最低」優先排序；折數相同時，再依與目標金額的絕對差距排序。
  - 若沒有任何組合落在可接受範圍內，改列最接近目標的超額備選並顯示提醒。
  - 列出前 5 名最佳搭配組合，顯示詳細購買數量、總原價、折後實際金額與差距標籤（如 `完全命中`、`少 $X 元` 或 `多 $X 元`）。
  - **回饋明細與總額**：個別顯示該組合的「折價券省下金額」、「蝦幣回饋金額」以及「回饋總額（折扣+蝦幣）」。

## 🛠️ 技術架構

- **前端技術**：純原生 HTML5 / CSS3 / JavaScript (ES6+)
- **無第三方套件依賴**：完全無需安裝 `npm` 套件或後端伺服器，直接使用瀏覽器開啟即可執行。
- **無快取機制 (No-Cache)**：在 `<head>` 設定了 `Cache-Control`、`Pragma` 與 `Expires` 標籤，確保每次造訪皆讀取最新網頁版本。
- **響應式雙欄佈局 (Two-Column RWD)**：左欄為已匯入商品清單與試算表格，右欄為優惠設定與試算結果面板，在大螢幕下視覺並排清晰，行動裝置下自動彈性堆疊。

---

## 🚀 使用說明

1. **開啟應用**：使用任意現代瀏覽器開啟 `index.html`。
2. **匯入商品**：在文字框中輸入或貼上商品價格（每行一筆），點擊 `📥 匯入商品價格至列表`。
3. **設定優惠**：輸入折價券折數、折價上限、蝦幣回饋 % 數及蝦幣上限，上方面板會隨即顯示試算結果。
4. **精算組合**：
   - 在「組合推薦計算設定」區塊輸入您的目標折後金額與商品數量上限。
   - 點擊 `🔍 開始精算最佳折數組合 (TOP 5 排名)` 即可查閱最佳搭配方案。
